🍔 Food Delivery Route Optimizer

📌 Project Overview

Food Delivery Route Optimizer is a Java-based project that uses Data Structures and Algorithms (DSA) to find the shortest and most efficient delivery routes.

The main objective is to reduce delivery distance and time by finding the optimal path between different locations using graph algorithms.

🎯 Objectives

- Find the shortest delivery route.
- Optimize delivery distance.
- Reduce delivery time.
- Apply real-world DSA concepts.

🛠️ Technologies Used

- Java
- Data Structures and Algorithms
- Graph Theory
- Dijkstra's Shortest Path Algorithm
- Priority Queue

🧠 DSA Concepts Used

1. Graph – Represents locations and routes.
2. Dijkstra's Algorithm – Finds the shortest path.
3. Priority Queue – Helps select the minimum-distance node efficiently.

⚙️ Features

- Shortest path calculation.
- Efficient route optimization.
- Graph-based location management.
- Distance-based route selection.

▶️ How to Run

1. Clone the repository:
   "git clone https://github.com/ashutoshthakur712-cell/Food-Delivery-Route-Optimizer.git"

2. Open the project folder.

3. Compile the Java program:
   "javac Main.java"

4. Run the program:
   "java Main"
